# Стили интерфейса

Основные цвета и размеры находятся в `tokens.css`. Общие кнопки, поля, окна и
уведомления - в `components.css`. Стили отдельных экранов лежат в `App.css`
и `Workbench.css`, каталога и страниц проектов — в `components/Catalog.css`
(относительно `src`). Малые элементы используют `--radius-small`, который
учитывает радиус выбранной темы и ограничивает скругление до 4 px.

Не добавляйте цвет прямо в компонент, если для него уже есть переменная. После
изменения CSS запустите:

```bash
npm run check:design-system
npm run build
```

Общие иконки находятся в `components/ui.tsx`. Системная иконка приложения
создаётся из `assets/brand/icon.svg` командой `npm run icons`.

## Темы

Встроенные темы описаны в `theme.ts`. Импортируемый файл имеет формат
`vlauncher-theme`, версию 1, название, набор цветов и радиус от 0 до 24 px.
Поддерживаются HEX, RGB и RGBA. Размер файла ограничен 128 КБ.

Приложение хранит до 50 пользовательских тем. На десктопе файл читает Tauri, а в
браузере используется обычная загрузка файла.
