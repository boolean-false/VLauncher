# Приватность

Здесь описано только поведение приложения VLauncher. У сайта VSpace, GitHub и
Discord могут быть свои правила.

## Что хранится на компьютере

Профили, миры, настройки и кэш хранятся локально. Токен VSpace сначала
сохраняется в Secret Service на Linux, Credential Manager на Windows или
Keychain на macOS. Если системное хранилище не работает, используется файл в
папке настроек VLauncher. На Unix он доступен только текущему пользователю
(`0600`).

GitHub-токен для сборок main сохраняется только в системном хранилище. Если оно
недоступно, токен живёт в памяти до закрытия VLauncher. В логи токены не
записываются.

## Статистика

При первом запуске VLauncher спрашивает разрешение на отправку статистики. Пока
ответа нет или выбрано «Нет», ничего не отправляется.

Если статистика включена, отправляются:

- запуск лаунчера или игры и день активности;
- версия приложения и семейство ОС;
- просмотр или установка опубликованного проекта;
- случайный идентификатор установки без имени аккаунта.

Имена миров, локальные пути и список личных пакетов не отправляются. События
хранятся 90 дней. Запись об установке удаляется после 90 дней без активности.
После отключения статистики новые события не отправляются, а локальный
идентификатор удаляется.

Сервер, как и любой HTTPS-сервис, видит IP-адрес и User-Agent запроса.

## Discord

Если включить Discord Rich Presence, приложение передаёт локальному Discord
состояние «в лаунчере» или «играет» и время начала. Названия профилей и миров не
передаются. VSpace в этом не участвует.

## VSpace и GitHub

Авторизация работает через GitHub Device Flow. Токен добавляется только к
запросам, для которых нужен вход, и не отправляется вместе со статистикой.
Текст, изображения и файлы, которые пользователь сам публикует или отправляет
через форму, передаются в API VSpace.
