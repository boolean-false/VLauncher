VLauncher 1.4.1

- Исправлена ошибка запуска после смены версии VoxelCore в профилях с символическими ссылками внутри локальных паков. При неизменном составе установленных пакетов лаунчер сохраняет папку content на месте.
- В профилях без контента из каталога служебный файл .vlauncher-revision восстанавливается после удаления без перекопирования локальных паков.
- При подготовке новой версии пака требование к DEV-сборке переносится из предыдущей опубликованной версии, если требуется та же будущая версия VoxelCore. Добавлена кнопка восстановления прежнего требования к движку. Обновление списка DEV-сборок сохраняет выбранный коммит, даже если старого архива уже нет в списке.
