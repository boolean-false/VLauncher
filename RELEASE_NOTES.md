VLauncher 1.4.2

- Исправлена установка паков с требованием к DEV-коммиту после выхода стабильной версии VoxelCore. Совместимость со стабильным движком теперь подтверждается по официальному релизу и файлу для нужной платформы.
- При ошибке совместимости выбранного движка лаунчер сначала проверяет доступные стабильные релизы со всем набором зависимостей. Переход на подходящую стабильную версию показывается в предпросмотре установки; если релиз ещё не вышел, сохраняется подбор совместимой DEV-сборки.
- Исправлено быстрое добавление beta-паков из каталога: учитывается канал выбранного релиза, в том числе для Quartz и Neutron.
- Упаковка macOS DMG вынесена в отдельный шаг с подробным журналом и повторными попытками без повторной компиляции приложения.
