VLauncher 1.3.0

- Версию контент-пака теперь можно опубликовать в Мастерской прямо из публичного GitHub Release. Доступны приложенные ZIP-архивы и автоматический архив исходного кода для выбранного тега.
- VLauncher показывает размер файлов и ход загрузки из GitHub, проверяет подготовленный пакет и переносит описание релиза в список изменений.
- Выбранный GitHub-репозиторий и источник файлов запоминаются локально отдельно для каждого проекта. Предрелизы автоматически получают канал "Бета", а повторная отправка уже существующей версии блокируется.
- Аналитика проектов корректно строит выбранный показатель по всем дням периода и отдельно показывает данные за текущий день по UTC.
- Встроенные пакеты VoxelCore, например `base`, теперь правильно обозначаются в зависимостях и не открываются как отсутствующие проекты
