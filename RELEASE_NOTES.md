VLauncher 1.3.9

- Карту теперь можно опубликовать из отдельной папки или ZIP-архива, не импортируя её предварительно в игровой профиль. Поддерживаются архивы с `world.json` в корне или в одной папке карты.
- Для отдельной карты игровой профиль необязателен. Без него версию VoxelCore можно указать вручную; с профилем лаунчер возьмёт из него версию игры и доступные зависимости.
- Перед подготовкой отдельной карты лаунчер показывает вложенные контент-паки и конкретные ID из `packs.list`, которых не хватает для публикации. Файл данных игрока `player.json` не попадает в итоговый архив.
