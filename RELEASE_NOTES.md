VLauncher 1.3.2

- В Мастерской совместимость с VoxelCore теперь настраивается отдельно для каждой версии контента. Начальное значение берётся из зависимости `base`, но его можно изменить перед публикацией.
- Контент для ещё не выпущенной версии VoxelCore можно привязать к минимальному коммиту ветки `main`. Лаунчер предупреждает о таком требовании и проверяет совместимость выбранной экспериментальной сборки при установке.
- После выхода подходящей стабильной версии VoxelCore требование экспериментальной сборки автоматически перестаёт применяться.
- Снятую версию контента можно повторно опубликовать с тем же номером.
- Исправлена загрузка автоматических ZIP-архивов исходного кода из GitHub Releases.
- Окно просмотра проекта в панели управления стало шире.
