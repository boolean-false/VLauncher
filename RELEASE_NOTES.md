VLauncher 1.3.6

- Для установки экспериментальных сборок VoxelCore больше не нужно входить в GitHub и предоставлять право `public_repo`.
- Архив выбранной сборки скачивается через `nightly.link`, а сведения о сборке лаунчер получает из публичного GitHub API.
- Перед установкой по-прежнему проверяются официальный репозиторий, workflow, commit SHA, размер и контрольная сумма архива.
