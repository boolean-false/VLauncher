VLauncher 1.1.1

- Состав пакетов мира в профиле теперь отображается компактно, без склеенных названий и повторного перечисления установленных пакетов как отсутствующих.
- Большие списки пакетов мира раскрываются отдельно и не растягивают страницу профиля.
- Исправлена установка пакетов VoxelWorld с нестандартными версиями в `package.json`: несовместимое значение безопасно заменяется на `0.0.0` только для этой интеграции.
- Исправлен вход в Мастерскую на системах, где встроенный интерфейс не мог подключиться к VSpace.
- Если браузер не открылся автоматически, лаунчер продолжает вход и показывает ссылку GitHub вместе с кодом подтверждения.
- Ошибки подключения к VSpace и GitHub при входе теперь объясняются понятным сообщением.
