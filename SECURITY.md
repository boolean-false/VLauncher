# Безопасность

Исправления безопасности делаются для последней версии VLauncher. Ветка `main`
может содержать ещё не выпущенные изменения.

Если вы нашли уязвимость, не создавайте открытый issue. Откройте в репозитории
**Security → Report a vulnerability** и приложите версию программы, ОС, шаги
воспроизведения и возможные последствия. Токены, личные данные и рабочий
proof-of-concept тоже отправляйте только туда.

Обычные ошибки можно оформлять через шаблон bug report.

В этом репозитории находится клиент VLauncher. Проблема может относиться к VSpace
или VoxelCore, но её всё равно можно прислать через приватный отчёт - разберёмся,
куда она относится.
